# NhemDangFugBixs.Tooling Samples

This package ships marker-first samples to help teams adopt generated VContainer registrations safely.

## Included samples

- `BasicAutoRegister`: minimal service + scope mapping + generated installer call.
- `ScopeMarkerArchitecture`: layered asmdef-friendly marker architecture.
- `MessagePipeIntegration`: broker registration and consumer metadata reporting.
- `SceneComponents`: scene component registration with `RegisterComponentInHierarchy`.

Each sample is intentionally small so you can copy patterns into your own architecture.
