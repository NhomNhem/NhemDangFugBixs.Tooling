# Codex Workflow — Update Docs

Use this when public behavior changes.

## Steps

1. Update README for core user-facing changes.
2. Update `Documentation~/` for detailed docs when present.
3. Update `Samples~/` if examples are outdated.
4. Update `CHANGELOG.md` when behavior changes.
5. Include code examples:
   - Input attribute usage
   - Generated intent
   - Common mistakes

## Style

Prefer practical examples over abstract explanation.
Do not claim this package replaces VContainer.
Use:

```txt
This package improves VContainer workflow. It does not replace VContainer.
```
