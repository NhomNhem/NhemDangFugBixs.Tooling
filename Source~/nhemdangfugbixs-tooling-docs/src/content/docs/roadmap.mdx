## Current Stable Focus

- Scope marker mapping
- Auto registration core attributes
- Entry point and scene component support
- Essential diagnostics for mapping and injection safety

## Near-Term

- Stronger CLI report and graph workflows
- Richer Editor diagnostics UX
- Expanded analyzer code fixes

## Later

- Advanced bindings (keyed, open generic, collection)
- Optional prefab/scriptable helpers
- Additional AI-friendly architecture exports

## Non-Goals

- Replacing VContainer
- Forcing one project architecture naming convention
