Reports make architecture state visible and reviewable.

## Common Outputs

- `docs/generated/di-map.md`
- `docs/generated/di-graph.mmd`
- `docs/generated/service-index.json`

## Why They Matter

- Humans can review registrations and scope boundaries quickly.
- AI coding agents can read architecture context before generating code.
- CI can preserve report history to spot architectural drift over time.
