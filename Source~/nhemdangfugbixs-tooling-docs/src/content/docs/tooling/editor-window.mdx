Menu path:

```txt
Window/Nhem/DI Diagnostics
```

## What You Can Do

- Inspect scope marker mappings.
- Browse services by scope and assembly.
- View warnings/errors before entering Play Mode.
- Trigger report generation for team sharing.

Treat this window as your in-Editor DI health dashboard.
