---
title: Scene Components
description: Register existing MonoBehaviour scene components through generated VContainer installers.
slug: docs/guides/scene-components
---

Use `RegisterComponentInHierarchy` intent for scene-owned `MonoBehaviour` types.

```csharp
[AutoRegisterIn<IGameplayScope>(Lifetime = NhemLifetime.Scoped)]
[RegisterComponentInHierarchy]
[As<IPlayerView>]
public sealed class PlayerView : MonoBehaviour, IPlayerView { }
```

Generated intent:

```csharp
builder.RegisterComponentInHierarchy<PlayerView>()
    .As<IPlayerView>();
```

## Notes

- This guide covers existing scene components only.
- User `LifetimeScope` classes remain user-owned.
- Constructor injection in `MonoBehaviour` is still a bad fit; prefer method/property injection where needed.
