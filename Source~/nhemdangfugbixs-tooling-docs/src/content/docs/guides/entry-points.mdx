---
title: Entry Points
description: Register lifecycle services as VContainer entry points.

---

Use `[EntryPoint]` for classes that intentionally participate in VContainer lifecycle flow.

```csharp
[AutoRegisterIn<IGameplayScope>(Lifetime = NhemLifetime.Scoped)]
[EntryPoint]
public sealed class PhaseFlowEntryPoint : IStartable, ITickable
{
    public void Start() { }
    public void Tick() { }
}
```

Generated intent:

```csharp
builder.RegisterEntryPoint<PhaseFlowEntryPoint>();
```

## Notes

- `[EntryPoint]` is recommended even when lifecycle interfaces can be auto-detected.
- Keep entry points orchestration-focused.
- Invalid `[EntryPoint]` usage is reported as `NHEM_DI_040`.
