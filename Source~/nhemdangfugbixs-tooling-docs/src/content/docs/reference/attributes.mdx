## Phase 1/2 Attributes

| Attribute | Purpose | Applies To |
| --- | --- | --- |
| `AutoRegisterIn` / `AutoRegisterIn<TScope>` | Declare scope + lifetime registration | Class |
| `LifetimeScopeFor` / `LifetimeScopeFor<TScope>` | Map marker to concrete `LifetimeScope` | User-owned `LifetimeScope` class |
| `As<T>` / `As(typeof(T))` | Bind explicit contract | Class |
| `AsSelf` | Bind concrete type | Class |
| `EntryPoint` | Register lifecycle type as entry point | Class |
| `RegisterComponentInHierarchy` | Register existing scene component | `MonoBehaviour` |

The generated extension namespace is:

```csharp
using NhemDangFugBixs.VContainer;
```
