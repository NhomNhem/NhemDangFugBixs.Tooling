## What you will build

A minimal marker-based flow:

1. Define a scope marker.
2. Annotate a service.
3. Map the marker to a concrete `LifetimeScope`.
4. Call the generated extension.

## Step 1: Create a scope marker

```csharp
public interface IScopeMarker { }
public interface IGameplayScope : IScopeMarker { }
```

## Step 2: Create service contract + implementation

```csharp
using NhemDangFugBixs.Attributes;

public interface IPhaseStateMachine { }

[AutoRegisterIn<IGameplayScope>(Lifetime = NhemLifetime.Scoped)]
[As<IPhaseStateMachine>]
public sealed class PhaseStateMachine : IPhaseStateMachine { }
```

## Step 3: Map marker to a user-owned `LifetimeScope`

```csharp
using NhemDangFugBixs.Attributes;
using NhemDangFugBixs.VContainer;
using VContainer;
using VContainer.Unity;

[LifetimeScopeFor<IGameplayScope>]
public sealed class GameplayLifetimeScope : LifetimeScope
{
    protected override void Configure(IContainerBuilder builder)
    {
        builder.RegisterGeneratedFor<IGameplayScope>();
    }
}
```

## Step 4: Check generated behavior

The generated installer stays close to normal VContainer code:

```csharp
builder.Register<PhaseStateMachine>(Lifetime.Scoped)
    .As<IPhaseStateMachine>();
```

## Phase 2 options

Entry point:

```csharp
[AutoRegisterIn<IGameplayScope>(Lifetime = NhemLifetime.Scoped)]
[EntryPoint]
public sealed class GameplayBootstrap : IStartable
{
    public void Start() { }
}
```

Generated output:

```csharp
builder.RegisterEntryPoint<GameplayBootstrap>();
```

Scene component:

```csharp
[AutoRegisterIn<IGameplayScope>(Lifetime = NhemLifetime.Scoped)]
[RegisterComponentInHierarchy]
[As<IPlayerView>]
public sealed class PlayerView : MonoBehaviour, IPlayerView { }
```

Generated output:

```csharp
builder.RegisterComponentInHierarchy<PlayerView>()
    .As<IPlayerView>();
```

## Important policy

- `LifetimeScope` classes are user-owned.
- The generator does not create `LifetimeScope` MonoBehaviours by default.
- The generated extension namespace is `NhemDangFugBixs.VContainer`.
- The generated path is stateless and does not cache `IObjectResolver`.
